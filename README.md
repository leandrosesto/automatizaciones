# Leandro Sesto | Automatización de tareas administrativas

Automatizo las tareas administrativas repetitivas de empresas de cualquier rubro: planillas, PDFs, carpetas e informes. Trabajo de forma remota en toda Latinoamérica, con precio cerrado por proyecto y diagnóstico inicial sin costo.

Sitio web: https://leandrosesto.github.io/automatizaciones/

## Trabajos realizados

- **Panel de gestión:** reemplazó un circuito de planillas y papel por un sistema único para todas las áreas, con consulta de datos en segundos.
- **Creador de carpetas:** genera estructuras de carpetas completas a partir de una lista o una captura de pantalla. Más de 40 horas por mes recuperadas.
- **Unificador de expedientes:** ensambla, ordena, numera y verifica documentos PDF. 90 % menos de tiempo de armado.

## Herramienta gratuita

Unificador de PDF para Windows, offline y sin límite de archivos. Los documentos se procesan en tu propia computadora.
Descarga: https://github.com/leandrosesto-aut/automatizaciones/releases/tag/v1.0.0

## Herramientas

Python, Google Apps Script, Google Sheets y Drive, procesamiento de PDF y OCR, integración de sistemas.
